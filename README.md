# ForgePoint Engineering

Portfolio demonstration website for **ForgePoint Engineering**, a fictional UK industrial engineering consultancy.

> ForgePoint Engineering is not a real company. All case studies are concept/fictional and all contact details are illustrative.

## Tech

Plain HTML, CSS and vanilla JavaScript. No frameworks, no build step — open `index.html` in a browser.

## Structure

```
index.html  about.html  services.html  industries.html  projects.html  contact.html
css/styles.css      Shared stylesheet (design tokens, layout system, header, footer)
js/main.js          Shared script (mobile menu, header scroll state, copyright year)
assets/             Logo mark, SVG icons and illustrations
```
